## What it is

A numbered callout list. The hook tells the viewer they are probably doing things
they shouldn't be, then delivers a fixed count of concrete behaviors, each backed
by an authority — in the Christian niche, scripture. It works because it
implicates the viewer directly instead of offering neutral advice.

## Beat-by-beat skeleton

1. **Cold-open count hook.** No greeting, no intro, no self-introduction. States
   the count and the condition in one sentence: *"There are four things you
   should not be doing if you claim to be a Christian."*
2. **Item block, repeated once per item.** Each block runs:
   - **Label** — "Number [ordinal] is [behavior]." The behavior is a concrete
     action, not an abstract quality.
   - **Authority anchor** — the scripture reference, spoken naturally.
   - **The content of the verse** — paraphrased, not read formally.
   - **Application line** — a sharp reframe aimed at the viewer, often closing
     the escape hatch: *"If you're only saying it because they're not in the
     room, that's gossip."* Not present on every item.
3. **Self-implication.** On one item — item four in both seeded scripts — the
   speaker admits the same sin: *"and I was so guilty of this."* It lands right
   before the CTA and turns accusation into shared struggle.
4. **CTA bridge.** The list is tied back to one root cause (not being in
   scripture consistently), which hands off to the product:
   destination → text the number → what Folk does → comment keyword.

## Length / timing

190-215 words as delivered across both seeded scripts. At typical talking-head
pace that is roughly 60-75 seconds.

### Christian

The authority anchor is scripture and it is non-negotiable — every item in both
seeded scripts carries a book, chapter, and verse. Items are sins, and the hook's
condition is an identity challenge ("if you claim to be a Christian") rather than
a neutral descriptor.

**What the 200k+ script did differently from its 20-30k peer.** Structure, CTA,
and length were effectively identical, so item selection was the variable:

| 20-30k version | 200k+ version |
|---|---|
| gossip | cussing |
| consuming content | attending sinful places (concerts, the bar, a party) |
| dating someone who doesn't love God | worshiping other idols |
| only talking to God when you need something | using the Lord's name in vain |

The winner's items are **behaviors people actively do and openly defend**. The
weaker set leans on internal or relational habits that are easier to nod along
with. Every winning item is also a single observable action rather than a
disposition.
